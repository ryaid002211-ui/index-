# الاداري برو (SmartAdminPro)

Native Android application built with Kotlin, Jetpack Compose, and Material 3.

## Features

- **Home & Clock Sections**: Dashboard with specialty filters, sales/monitor/debts sections, and quick navigation.
- **Invoices & Weekly Folders**: Seller and buyer invoice editors, folder organization, and PDF printing/sharing.
- **Weekly Filters & Detail Tables**: Filtered weekly summaries and detailed breakdown editors.
- **Debts & Cashboxes**: Debt cashboxes, automated debt box, account ledgers, and currency monitor controls.
- **Tasfeer (Currency Exchange)**: Exchange operations, sub-views, and calculation modals.
- **Private Accounts**: Private folders, account statements, and app lock (PIN / biometric).
- **Buyer Hub**: Buyer folders, transfer sheets, annual sheets, and sales/profit controller ledgers.
- **Settings & Backup**: Bilingual Arabic/English support, dark/light theming, custom fonts, JSON backup import/export via Room & DataStore, and Google Drive backup.

## Tech Stack

- Kotlin & Jetpack Compose (Material 3)
- Navigation Compose
- Room Database + DataStore Preferences
- WorkManager & OkHttp (Google Drive backup)
- Coil for image loading
